# 酷狗音乐解析指南

## 支持范围

- 移动端 MV 分享链接：`m.kugou.com/mv/?hash=...`、`m3ws.kugou.com/mv/?hash=...` 与 `t1.kugou.com` 短链。
- 歌曲分享页与短链：`m.kugou.com/share/song.html?chain=...`、`m.kugou.com/share/default.html?chain=...` 与 PC 端重定向分享页 `kugou.com/share/<chain>.html`。
- 歌曲音频：可返回公开、免费的高品质音频直链；付费歌曲和试听片段只返回元数据，不会误报为完整音频。

## 提取字段

MV 可提取标题、歌手、封面与所有公开 MP4 清晰度；免费歌曲可提取标题、歌手、封面及音频直链地址。

## 实现说明

- **MV 解析**：播放信息来自酷狗移动端公开接口。解析器按官方网页的参数排序与 MD5 方式生成临时签名，再优先返回 SQ、RQ、LE、SD 清晰度。
- **歌曲解析**：通过提取分享链标识（`chain`）获取歌曲详细信息（`songName`、歌手信息、专辑封面、高品质 MP3 播放直链），并兼容 PC 端与移动端不同重定向形态。
- **链接有效期**：返回的直链地址带有官方时效性签名，应在取得后尽快播放或下载。

## 限制

- DRM、付费或明确标注试听的歌曲不会返回音频直链。
- 分享页下架、地区限制或接口风控时会返回空媒体结果。
